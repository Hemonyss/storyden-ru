# Storyden

Storyden — это платформа для управления сообществом и контентом, где бы они ни находились. Запустите форум, блог, публикуйте новости, создавайте подборки интересных сайтов, создайте каталог, базу знаний и многое другое. "Подробнее здесь" (https://www.storyden.org/docs/introduction/what-is-storyden).

Если вы хотите помочь с исследованием, пожалуйста, заполните эту небольшую (анонимную) форму: https://airtable.com/shrLY0jDp9CuXPB2X

Вы можете попробовать её прямо сейчас! Запустите образ и откройте http://localhost:8000 в браузере:

```sh
docker run -p 8000:8000 ghcr.io/southclaws/storyden
```

## Релизы и версии

Storyden выпускает версии с простым номером версии, который относится ко всему продукту в целом, а не к API. По этой причине мы не используем «семантическое версионирование» и стараемся по возможности избегать ломающих изменений API. Иногда ломающие изменения всё же могут происходить, но они всегда будут описаны и отмечены в примечаниях к релизу, а также вынесены в отдельный список ломающих изменений.

```
  v1.25.8
   │ │  │
   │ │  └── Релиз: Инкремент для каждого релиза в году.
   │ └───── Год: релизы выходят часто, поэтому для простоты мы используем отметку года.
   └─────── Мажорная: всегда будет 1.
```

Этот формат был выбран для совместимости с реестрами пакетов и ожиданиями разработчиков, но он не соответствует семантическому версионированию — скорее это «номер сборки», подобно тому, как версии обозначаются в видеоиграх.

Вне коммита/образа релиза номера версий внутри файлов и API получают суффикс "-post", чтобы указать, что вы используете версию, находящуюся за пределами стабильного релиза.

## Что умеет Storyden

> https://www.storyden.org/docs/introduction/what-is-storyden

Storyden — это современный форум, вики и центр сообщества. Как интернет-форумы прошлого, но с новым внешним видом, современной системой безопасности, возможностями развёртывания и интеллектуальными функциями. Дискуссионный форум, рабочее пространство Notion и собственная платформа Reddit — всё в одном. Ваше сообщество может использовать её для обсуждений, обмена ссылками или создания каталога знаний и структурированных данных.

Это проект с открытым исходным кодом, "который очень легко разместить самостоятельно" (https://www.storyden.org/docs/introduction/vps), и дань уважения интернету 2000-х!

## Почему

> https://www.storyden.org/blog/building-running-administrating-modern-forum-software

Если вкратце: большинству форумов уже несколько десятилетий, они небезопасны, заброшены или просто некрасивы. Storyden стремится решить все эти проблемы с помощью современного языка, простого развёртывания и красивого дизайна.
